# Verilog Projects

A collection of Verilog HDL exercises covering combinational arithmetic and sequential logic.

## Designs

| File | Description |
| --- | --- |
| `ripplecarryadder.v` | 4-bit ripple-carry adder built from full-adder stages. |
| `Mod-10_Upcounter_DFF.v` | Mod-10 up-counter using D flip-flops. |
| `UP-Down-Counter(d).v` | Up/down counter design with a configurable modulus. |
| `Up-Down-Counte(Syn)r.v` | Synchronous up/down counter design. |
| `SerialShifter.v` | Serial shifter design. |

Each source file contains its Verilog module definitions. Select the design you want to simulate or synthesize and use the appropriate tool and testbench for your project.
